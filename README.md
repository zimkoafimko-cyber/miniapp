# Telegram Mini App — Task Stars

Готовый минимальный проект: бело-серый Telegram Mini App + Node.js/SQLite.

## Важно
1. Создай бота через @BotFather и получи BOT_TOKEN.
2. Добавь бота администратором в канал @belcryptoo — это нужно для проверки подписки.
3. На хостинге задай переменные из `.env.example`.
4. WEBAPP_URL — публичный HTTPS-адрес приложения.
5. В @BotFather создай кнопку Menu Button или Web App и укажи этот HTTPS-адрес.

## Запуск локально
Node.js 20+:
```bash
npm install
BOT_TOKEN=... ADMIN_USERNAME=AlinaResseler CHANNEL_USERNAME=belcryptoo npm start
```

## Бесплатный хостинг
Проект рассчитан на обычный Node.js-хостинг с бесплатным тарифом, если он предоставляет persistent disk для SQLite. Если файловая система эфемерная, замени SQLite на PostgreSQL/другую постоянную БД.

## Ограничение проверки «отправил пост»
Telegram Mini Apps не дают серверу универсального доказательства, что пользователь действительно отправил сообщение конкретному человеку после открытия share sheet. Поэтому текущая версия награждает после запуска share flow. Если нужна строгая проверка фактической отправки, потребуется изменить механику задания (например, подтверждаемая ссылка/бот в целевом чате).
